# 更新日志

这里记录快贴（KwikPaste）的重要变更。

## 2.0.8 - 2026-10-24

- 文本记录可以在单独的窗口里编辑，窗口大小可以调整；在预览里双击正文也能直接编辑。
- 多选的图片和文件可以一起粘贴、复制，或拖到其他应用。
- 预览和大图里可以识别图片中的二维码并复制内容，复制的内容会记成一条新记录。
- 卡片上的快捷信息支持右键菜单：复制、粘贴这一段，链接和邮箱还能直接打开；中键点链接或邮箱也会直接打开。
- 新增「「全部」中不显示收藏」：收藏的记录只在「收藏」里显示，搜索时仍能找到。
- 图片记录可以「在资源管理器中显示」（macOS 上是「在访达中显示」）保存的原图。
- 「上报问题」可以留一个回复邮箱（选填），诊断信息里加上了系统版本和硬件信息。
- macOS 版改用固定证书签名，以后更新不再需要重新授予辅助功能权限（从旧版更新到 2.0.8 这一次还需要授权一次）。
- 快捷信息和拆词把 05/28、2026-05-28 这样的日期作为一整段，不再拆开。
- 剪贴板窗口两侧放不下预览窗时（比如竖屏），改放到上方或下方，尽量不挡住剪贴板窗口。
- 预览里的快捷信息区限制了高度，片段多时在区内滚动；「拆词」只对当前这次预览生效，不再改动预览方式设置。
- 粘贴为纯文本时去掉末尾的空格和换行。
- 粘贴按键被系统拦截（常见于游戏反作弊）时给出提示，可以一键重启快贴恢复自动粘贴。
- 修复 Windows 上点击后马上拖动面板空白处时，面板拖不动的问题。
- 修复列表滚动过后，复用的记录没有立即移到顶部的问题。
- 修复 Windows 上用带 Alt 的快捷键唤起剪贴板窗口时，资源管理器里正在进行的重命名被打断的问题。
- 修复 Windows 上开启 Equalizer APO 时复制提示音不响的问题。
- 修复在预览里切换图片 / 文字或拆词视图时，预览窗上下跳动的问题。
- 修复较长的子菜单超出窗口、无法用滚轮滚动的问题。
- 修复窗口较矮时对话框底部按钮被挡住的问题。

## 2.0.7 - 2026-10-18

- 修复 Snowshot 等截图工具截图后，图片有时没有被记录的问题。
- 修复自动更新后「以管理员身份运行」失效、快贴以普通权限运行的问题。
- 修复列表里显示过图片后，系统的文件选择窗口有时卡住打不开的问题。

## 2.0.6 - 2026-10-18

- 新增大图预览：从预览窗、右键菜单「查看大图」或按 Shift+Space 打开图片原图。识别出的文字叠在图片原位，可以拖选、双击选中整行、Ctrl/Cmd+A 全选、Ctrl/Cmd+C 复制，按 T 高亮文字区域；复制出来的文字会记成一条新记录。
- Windows 上新增 PP-OCRv6 文字识别引擎，分轻量、标准、高精度三档，在扩展页的图片文字识别里下载切换，小字、代码和网址的识别准确得多；换引擎后可以「全部重新识别」旧图片。
- 新增「文本匹配规则」：用正则表达式匹配复制的文本，显示为快捷信息、标记为敏感或不记录，内置身份证号、快递单号、IPv4、MAC 地址等模板。
- 新增「上报问题」：在偏好设置里把问题描述连同日志和诊断信息发给开发者，剪贴板内容不会上传。
- 编辑过的记录会保留原文，可在右键菜单「恢复原文」；图片记录可以「粘贴为文件」；多选的文本记录可以合并成一段粘贴或复制。
- 预览里的 HTML 记录按文档结构显示；点击预览中的文件行可在文件管理器中定位；预览窗与记录的间距可以设置。
- 复制提示音可以选择音色：经典、啾啾、气泡、叮咚、轻敲。
- 新版本改为在后台下载，在电脑空闲 10 分钟且没有打开快贴窗口时自动安装。
- 所有快捷键集中到一页，剪贴板窗口内的按键也可以重新设置；Ctrl/Cmd+E 打开内容编辑。
- 偏好设置里的下拉框换成带示意图的磁贴和分段按钮。
- 「亚克力」材质换成「磨砂」，整个窗口都是半透明的；Windows 上带标题栏的窗口改用自绘标题栏，和窗口内容是同一块磨砂。
- Windows 上按剪贴板的实际写入者识别来源应用，来源更准确；缩略图和预览按显示尺寸解码，更快也更省内存。
- 多行备注在卡片上合并成一行，用「 / 」分隔。
- 修复 Windows 上复制提示音开头被截掉、播放时卡顿的问题。
- 修复对话框里不能用鼠标滚轮滚动、拆分单词的预览在鼠标离开后不关闭的问题。
- 修复磨砂材质下下拉菜单、提示和对话框变透明，卡片出现深色描边的问题。

## 2.0.5 - 2026-10-15

- 新增「双击按键唤起」：快速连按两次 Ctrl、Alt、Shift（macOS 上还有 Command）即可打开或隐藏剪贴板窗口，可限定左侧或右侧的按键，在偏好设置的快捷键里开启。
- 快捷键冲突现在会直接在设置项下面提示是与哪个功能冲突，也会提示快捷键已被其他程序占用。
- 搜索框支持按时间、来源应用和类型筛选记录。
- 偏好设置重新分成 10 个标签页，不常用的选项折叠在「更多选项」里，搜索可以跨标签页查找。
- 文本预览里列出内容中的链接、邮箱、手机号、时间和编号等快捷信息，点一下只复制这一段；可以按类型着色（偏好设置里可关闭），预览里的链接可以直接点开，预览窗口与剪贴板窗口的间距也收紧了。
- 修复 Windows 上 Win+Shift+V 等组合键被误当作 Win+V 接管的问题，现在只接管单独的 Win+V。
- 修复自定义数据目录不可用（比如移动硬盘没插）时无法恢复默认目录的问题，并且不再允许把数据目录设在安装文件夹里。
- 修复首次运行时误删 1.x 留下的开机启动项。
- 修复 Windows 上快贴的隐藏窗口被部分游戏的反作弊程序误报的问题。
- 修复半透明窗口上圆角边框出现杂边的问题。
- 修复 macOS 上从固定的剪贴板窗口粘贴时目标应用没拿到按键、睡眠唤醒后应用被反复重启、偏好设置和引导窗口没有出现在最前面的问题。
- 修复拆分单词后选中的记录不是被点击的那条、备注光标不在末尾、点击后不能再次进入编辑的问题。

## 2.0.4 - 2026-10-14

- 新增「窗口布局」：可以切换为双栏，左边是剪贴板历史，右边常驻收藏和自定义分组，不用来回切换。
- 剪贴板窗口可以缩得更小，每栏最小 280×400。
- 搜索框加宽，占满顶部剩余宽度；偏好设置入口移到底部，底部还会显示当前选中的是第几项。
- 链接、邮箱、颜色、路径的类型标签改为彩色标记，更容易分辨；内容是链接的富文本（HTML、RTF）记录也能直接打开链接。新安装时快捷动作默认包含「打开链接」。
- 导入备份支持 EcoPaste 的备份文件，无法识别的备份文件会给出提示。
- 改为每 6 小时自动检查一次更新，检查失败时一小时后重试。发现新版本时弹出一次更新窗，关掉后剪贴板窗口顶部会一直显示「新版本」标记，同一个版本不再弹窗；原来的「自动检查更新」、检查频率和「跳过此版本」已移除。
- 偏好设置窗口可以缩得更小，侧栏可以收起并会记住收起状态，按 Esc 可以关闭窗口；侧栏底部的存储占用卡片已移除。
- 在搜索框中按一下 Esc 即可关闭剪贴板窗口，不用再按两下。
- 修复 Windows 上在 Excel 里拖动单元格时，Excel 提示剪贴板出现问题。
- 修复从剪贴板窗口打开偏好设置或更新窗口时，剪贴板窗口挡在前面的问题。

## 2.0.3 - 2026-10-11

- 修复已经知道有新版本时点「检查更新」，更新窗口高度不够，更新说明被截断、按钮压在文字上的问题。

## 2.0.2 - 2026-10-11

- 新增「偏好设置 › 扩展」：官方扩展可以在这里安装、启用、更新和卸载。扩展单独下载并经过签名校验，会在后台自动更新；不安装就不占用任何空间和内存。
- 新增扩展「图片文字识别」：复制图片后自动识别其中的文字，使用系统自带的识别能力，在本机完成，不上传。之后可以用图里的文字搜到图片，在右键菜单里「复制图中文字」，或在预览里切到「文字」挑选部分文字复制；「偏好设置 › 图片文字识别」可以查看识别进度。
- 新增扩展「微信输入法同步」：和手机上的微信输入法互传复制的文字和图片，用 6 位配对码配对。电脑上的微信输入法正在运行时由它负责互传，快贴只把手机发来的内容记进历史。这是非官方功能，微信输入法更新后可能失效。
- 文本记录可以编辑：在右键菜单里选择「编辑内容」，保存后带格式的内容会变成纯文本。
- 置顶的记录现在随列表一起滚动，不再固定在列表上方。
- 复制成功提示音移到「偏好设置 › 粘贴与复制」，可以调音量和试听，也能用「音效」「提示音」「声音」搜到。
- 「管理员权限启动」打开后会一直生效，而不是只提权一次，并会显示当前是否已以管理员身份运行。
- 单个图片文件现在归在「图片」分组；「清理缓存」会一并移除文件已不在磁盘上的文件记录，收藏和置顶的记录保留。
- 修复 Windows 上用 Alt+Tab 等方式切换前台窗口后，剪贴板窗口不会自动隐藏的问题。
- 修复在收藏范围内选择分类时，分类被忽略的问题。
- 修复复制 PNG 图片时偶尔因剪贴板被占用而被重新编码，导致同一张图重复出现在历史里的问题。
- 修复 Windows 上录制快捷键时 Windows 键被记成 Ctrl 的问题。
- 修复 Windows 上小字号中文的斜笔画有锯齿的问题。
- 「复制后隐藏窗口」的说明现在写明它只对复制生效，粘贴后窗口总会隐藏。

## 2.0.1 - 2026-10-09

- 更新窗口现在会显示新版本的更新要点摘要。

- 修复剪贴板窗口打开时，快贴会吞掉未绑定任何面板快捷键的按键的问题；现在直接按 Delete 即可删除选中的记录。
- 修复 Windows 上托盘菜单不跟随系统深色模式的问题。
- 修复 Windows 上剪贴板窗口在编辑激活后 Mica 边框变成纯色的问题。
- 修复 macOS 上部分窗口文字难以辨认、权限按钮没有打开对应隐私面板，以及双击剪贴板窗口顶部边缘会使其缩放的问题。

## 2.0.0 - 2026-10-08

- 快贴 2.0 正式版。整个应用改用 Rust 原生界面重写，不再使用 WebView，内存占用大幅降低、打开更快，界面也换上了新的样式。
- 可以直接覆盖安装在 1.x 上，记录、分组、设置和图片都会继续使用。1.x 不会自动更新到 2.0，请从官网或 GitHub 下载安装。升级后 1.x 无法再打开这份数据，如果之后可能退回 1.x，请先在 1.x 中「导出备份」。
- 新增局域网同步：在「偏好设置 › 同步」中开启后，用 6 位配对码配对同一网络中的设备，复制的文本和图片会实时互通。可以分别选择是否同步文本和图片、设置图片大小上限，也可以按地址手动添加设备。
- 新增「粘贴为纯文本」全局快捷键：不打开剪贴板窗口，把当前剪贴板内容去掉格式后直接粘贴。
- 新增「全屏应用中停用快捷键」和「在这些应用中停用快捷键」：前台是全屏应用（如游戏）或列表中的应用时，快贴的快捷键和鼠标按键唤起交还给该应用。
- 录制快捷键时，如果它已被其他程序占用或与快贴的其他快捷键冲突，会直接提示。
- 置顶和收藏的记录可以在剪贴板窗口中拖动排序。
- 「导出备份」和「导出为文件」合并为一个「导出」对话框。备份可以只包含收藏或指定分组，这种备份导入时只能合并；导入备份时可以选择是否同时导入其中的设置。
- 更新只保留一个渠道，「接收测试版更新」和「接收每日构建更新」选项已移除；Windows 上不起作用的「任务栏图标」选项也已移除。

## 1.4.0 - 2026-10-02

- 新增「导出为文件」：在「偏好设置 › 数据 › 备份迁移」中把记录导出为 Excel 或 Markdown，方便阅读、整理和分享。可以只导出收藏或指定分组，合并成一个文件或按分组拆分；敏感内容默认不导出。导出的文件不加密，也不能用来恢复数据，完整备份请继续使用「导出备份」。
- 新增应用内公告：快贴有重要通知（例如新版本发布）时，会在检查更新时以系统对话框告诉你，每天最多一次。点「不再提醒」后这条公告不再出现；关闭「自动检查更新」后，启动时不再获取公告。
- 新装的快贴默认关闭「空格键预览」，「文本预览方式」默认为「选词」。已有的设置保持不变。
- 修复一次复制偶尔生成两条相同记录的问题。
- 修复 Windows 中剪贴板窗口有时被其他置顶窗口挡住的问题。

## 1.3.8 - 2026-09-29

- 新增多选：点击剪贴板窗口底部的「多选」按钮，或在记录的右键菜单中选择「多选」，即可一次选中多条记录并删除。点击选择，按住 Shift 连选，按 Ctrl+A（macOS 为 ⌘A）全选。收藏和置顶记录仍按删除保护设置处理。
- 新增列表显示设置，位于「偏好设置 › 外观」：「列表风格」可选卡片或无间（记录贴边排列，用分隔线隔开）；「列表密度」可选舒适、标准、紧凑或自定义，选自定义时可以单独调整记录间距、上下内边距，以及是否显示头部行。
- Windows 新增「单击托盘图标打开」：可以选择单击托盘图标时打开剪贴板窗口还是偏好设置。在「偏好设置 › 通用」的「系统托盘图标」下设置，默认仍打开剪贴板窗口。
- 偏好设置界面更简洁：设置项不再带图标，只在需要时显示说明；「数据概览」成为侧栏中的独立页面。
- macOS 现在可以用 Homebrew 安装：`brew install --cask mansandadada/tap/kwikpaste`。
- 修复 Windows 中把文本拖到 WPS 等应用时无法放下的问题。
- 修复 Windows 调大「文本大小」后，偏好设置窗口无法缩小回 960×600 的问题。

## 1.3.7 - 2026-09-28

- 重做「偏好设置 › 数据」中的「自动清理」。记录改为按最后一次使用的时间过期，不再按第一次复制的时间：很早以前复制、至今每天还在粘贴的内容会被保留。即使关闭了「复用时更新记录」，从历史中复制或粘贴也算作使用。
- 新增自定义清理规则。可以给文本、图片、文件、敏感内容、来自某些应用的记录、超过指定大小的记录或只复制过一次的记录单独设置保留时长，从几分钟到永久保留。规则从上到下匹配，没有命中任何规则的记录按「默认保留时长」处理。内置大于 5 MB 的图片、敏感内容等常用规则，一键添加。
- 保存会立即删除记录的清理设置前，会先列出将要清理的条数和原因，确认后才保存。新增「清理状态」，显示最近一次清理的结果，并可「立即清理」。
- 自动清理现在也会保留放入自定义分组和写了备注的记录，与收藏、置顶一样。
- 清理设置修改后立即生效，不必等到下次启动，「自动清理周期」设置随之移除。「最大保留条数」在有新记录时即刻生效，存储上限也不再每分钟扫描一遍数据目录。
- 存储超出上限时，剪贴板窗口底部会给出提示：「仅提醒」模式下超限即提示，「自动清理」模式下在清理也无法回到上限以内时提示。点击提示可直接打开存储设置。
- 清理记录后数据库文件会随之变小。已有数据需在「偏好设置 › 数据」中执行一次「清理缓存」，压缩数据库并开启此功能。

## 1.3.2 - 2026-09-24
